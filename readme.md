# 🛠️ Automation Builder

A low-code workflow automation canvas built with **React Flow**, **Zustand**, and **TypeScript**. Create flows with draggable nodes, smart connections, edge editing, and real-time configuration.

🎥 [![Watch Demo](https://img.youtube.com/vi/aDdojiQHQc0/hqdefault.jpg)](https://youtu.be/aDdojiQHQc0)

## Features

- ⚡ Drag-and-drop node creation
- 🔗 Smooth edge connections
- ✏️ Edit node labels and configs
- 🧠 Zustand state management
- 💾 Save/load to localStorage
- ↩️ Undo/Redo support
- 📤 Export/import JSON
- 🧰 Configurable panel for nodes & edges

## Tech Stack

- React + TypeScript
- React Flow
- Zustand
- TailwindCSS
- Lucide Icons

## Setup

```bash
git clone https://github.com/devendramaharshi005/DragNBuild.git
cd automation-builder
npm install
npm run dev
```
